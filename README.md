# 🤳 Hilane Wala

### হাত কাঁপে? নাকি ফোন কাঁপানোর প্রতিভা আছে? এবার পরীক্ষা হোক! 😂

🌐 **Live Website:** https://hilanewala.netlify.app

## 🤔 আইডিয়াটা আসলো কোথা থেকে?

আমাদের এক বন্ধু আছে, যার হাত একটু বেশিই কাঁপে। তার মৃগী রোগের কারণে হাত কাঁপার বিষয়টি আমাদের পরিচিত ছিল। একদিন সেই হাত কাঁপা নিয়েই সে ট্র্যাকে একটা Rap বানিয়ে ফেলল! 😂

কিন্তু গল্প এখানেই শেষ না।

বাকি বন্ধুরা ব্যাপারটা নিয়ে মজা করতে করতে ভাবল, কে কতবার ফোন ঝাঁকাতে পারে, সেটা পরীক্ষা করলে কেমন হয়?

ব্যস! সেখান থেকেই জন্ম **Hilane Wala**-এর।

বন্ধুর একটা ঘটনা থেকে শুরু, আর এখন ব্যাপারটা দাঁড়িয়েছে Global Competition-এ! 💀

## 🎮 কীভাবে খেলবে?

1. ওয়েবসাইটে প্রবেশ করো।
2. নিজের Username দিয়ে Account তৈরি করো।
3. Login করে Home Page-এ যাও।
4. Start বাটনে চাপ দাও।
5. এবার ৬০ সেকেন্ড ধরে ফোন ঝাঁকাও!
6. দেখি কার ঝাঁকানোর ক্ষমতা কত! 😂

**সতর্কতা:** ফোনটা শক্ত করে ধরো। বন্ধুর রেকর্ড ভাঙতে গিয়ে ফোনটাই ভেঙে ফেলো না! 

## 🏆 কে সেরা?

Ranks সেকশনে গিয়ে দেখতে পারবে Global Top 10-এ কারা আছে।

নিজের Rank-ও দেখতে পারবে। এখন প্রশ্ন হলো, তুমি কি শুধু ফোন ঝাঁকাবে, নাকি Leaderboard-ও কাঁপিয়ে দেবে?
